# আমার দেশ, আমার তথ্য
তথ্য জানুন, তুলনা করুন, সিদ্ধান্ত নিন।

## Deploy on Render
1. GitHub Repo Connect করো
2. Build: pip install -r requirements.txt
3. Start: uvicorn main:app --host 0.0.0.0 --port $PORT

## নীতি
- অনুমান করা তথ্য প্রকাশ নয়
- তথ্য না থাকলে "পাওয়া যাচ্ছে না"
- প্রতিটি রেকর্ডে উৎস আবশ্যক
